# 제품 개요

- **문서 ID**: PROD-01
- **상태**: 동결
- **정본 범위**: 문제, 비전, 가치 제안과 성공 정의

## 문제

팀의 지식은 문서, 대화, 개인 메모와 외부 자료에 흩어진다. 토론에서 생긴 근거와 판단은
공식 문서로 수렴하지 않고, 생성형 AI는 조직의 권한·용어·확정 사실을 놓치면 신뢰할 수
없는 문장을 더 빠르게 만든다.

## 비전

사람의 생각과 토론이 `Draft → Review → Publish`를 거쳐 하나의 검증 가능한 조직 지식으로
수렴하는 웹 기반 팀 문서 시스템을 제공한다. AI는 작성과 검토를 돕지만 판단과 공식화는
항상 사람이 수행한다.

## 가치 제안

- 토론과 근거가 문서 변경 맥락으로 연결된다.
- Draft와 불변 Published Version을 분리해 공식 지식의 신뢰성을 보존한다.
- Search와 AI가 같은 Permission-safe Retrieval과 Source provenance를 사용한다.
- 조직 Vocabulary와 Writing Rules로 정확하고 읽기 쉬운 문서를 일관되게 만든다.

## 성공 정의

제품이 성공하려면 생각 입력부터 공식 Version 발행, 이후 검색과 재사용까지 하나의 흐름이
끊기지 않아야 한다. 구체적인 측정 계약은 [제품 지표](PRODUCT-METRICS.md)가 소유한다.

## 비목표

실시간 공동 타이핑, 범용 프로젝트 관리, AI 자율 발행, 익명 편집, 결제와 고객용 Public
API는 제품의 현재 경계가 아니다. 정확한 범위는 [전체 구현 범위](IMPLEMENTATION-SCOPE.md)를
따른다.
