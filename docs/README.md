# 문서 체계

이 저장소의 문서는 `제품 요구사항 → 도메인 → 상세 설계 → 구현` 순서로 구체화한다.

전체 문서 목록, 정본 경계와 상태는 [`DOCUMENT-MAP.md`](DOCUMENT-MAP.md)가 관리한다.

| 계층 | 질문 | 정본 위치 |
|---|---|---|
| 제품 | 누구의 어떤 문제를 왜 해결하는가 | `product/PRD.md` |
| 도메인 | 어떤 개념과 규칙으로 동작하는가 | `domain/` |
| 상세 설계 | 기능을 어떤 계약과 흐름으로 구현하는가 | `design/` |
| 태스크 | 왜, 어떤 범위로, 어떤 근거를 따라 작업했는가 | `tasks/` |

코드 작성 가능 여부는 파일 개수가 아니라 현재 태스크에 필요한 문서가 모두 구체화됐는지로
판단한다. 상세 기준은 저장소 루트의 `AGENTS.md`를 따른다.
