# 팀 문서 시스템

여러 사람이 AI의 도움을 받아 생각하고 토론한 결과를 정확하고 읽기 쉬운 공식 문서로
발전시키는 웹 기반 팀 문서 시스템이다.

현재 저장소는 구현보다 설계를 먼저 확정하는 단계다. 코드는 PRD, 도메인 문서와
태스크별 상세 설계가 준비된 뒤에만 작성한다.
