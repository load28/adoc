# 팀 문서 시스템

여러 사람이 AI의 도움을 받아 생각하고 토론한 결과를 정확하고 읽기 쉬운 공식 문서로
발전시키는 웹 기반 팀 문서 시스템이다.

전체 제품 설계는 동결됐다. 코드는 구현 태스크를 먼저 만들고 해당 요구사항에 연결된
제품·도메인·상세 설계와 테스트 계약을 필수 문서로 등록한 뒤에만 작성한다.
